# Task Manager

Python command-line task manager.

Features: Add, view, complete and delete tasks. Tasks are saved locally in JSON.

Run: python main.py

## Installation

Clone the repository:

```bash
git clone https://github.com/Madarax018/task-manager.git
cd task-manager
```

## Running the project

Run `python main.py`.

## Automated testing

Run the tests locally:

```bash
python -m unittest discover -s tests -v
```

GitHub Actions runs these tests automatically when
changes are pushed or a pull request is opened.
